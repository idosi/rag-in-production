# Remote Work and Device Security Policy { #remote-work-security-policy }

> SYNTHETIC DEMO DOCUMENT. A fictional internal policy written for a portfolio project. It does not describe any real firm.

Owner: Office Manager.

## Devices { #devices }

Client work is done only on firm laptops. Personal computers and phones may be used for email and the calendar, but client files may not be downloaded to them.

## Network { #network }

From outside the office, connect through the firm VPN before opening the shared drive or the accounting system. Public Wi-Fi is allowed only with the VPN on.

## Passwords and two-factor authentication { #passwords-and-2fa }

Every system that supports two-factor authentication must have it turned on. Passwords are kept in the firm's password manager and are never written in documents or shared in chat.

## Lost or stolen laptop { #lost-laptop }

Report a lost or stolen laptop to the Office Manager and to the Data Protection Lead within 1 hour. The Office Manager locks the laptop remotely.
