# Client Data Confidentiality Policy { #client-data-confidentiality-policy }

> SYNTHETIC DEMO DOCUMENT. A fictional internal policy written for a portfolio project. It is not legal advice and does not describe any real firm.

Owner: Data Protection Lead.

## Who may access client files { #who-may-access }

Only the bookkeeper who owns the client, the reviewer and the partners may open a client's restricted folder. Other employees ask the owner for the specific document they need.

## Sending files to clients { #sending-files }

Send client documents through the client portal, never as email attachments. If a client cannot use the portal, send a password-protected PDF and give the password in a phone call or text message, never in the same email.

## Personal data in notes and tools { #personal-data-in-tools }

Do not paste ID numbers, bank account numbers or salary data into chat tools, personal notes or AI assistants that are not approved by the Data Protection Lead. Refer to the client by client code (for example `CL-0142`) instead of by name when you discuss a case outside the client's folder.

## Reporting a data incident { #reporting-incidents }

If a document was sent to the wrong person, a laptop was lost, or you think someone accessed a client folder without permission, tell the Data Protection Lead within 1 hour of noticing. Do not try to fix it quietly. The Data Protection Lead decides whether the client and the authorities must be told.
