# VAT Return Preparation Procedure { #vat-return-preparation }

> SYNTHETIC DEMO DOCUMENT. A fictional internal procedure written for a portfolio project. Deadlines here are the firm's internal deadlines, not official ones, and nothing in it is tax advice.

Owner: Senior Bookkeeper.

## Internal deadline { #internal-deadline }

The firm's internal deadline for a draft VAT return is 5 business days before the official filing date. This leaves time for the reviewer and for questions to the client. Official filing dates are checked on the tax authority's website, not taken from this document.

## Preparing the draft { #preparing-the-draft }

Use the VAT report from the accounting system after the month is closed (see the month-end close procedure). Check that every purchase invoice above 5,000 has a valid supplier tax number. Invoices with a missing or invalid number are listed in the draft's notes and are not claimed until fixed.

## Review and submission { #review-and-submission }

The reviewer checks the draft against the previous period and asks about any change larger than 20%. Only a partner or the Senior Bookkeeper submits the return. Save the submission confirmation in the client's folder on the same day.
