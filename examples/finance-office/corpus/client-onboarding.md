# Client Onboarding Procedure { #client-onboarding-procedure }

> SYNTHETIC DEMO DOCUMENT. A fictional internal procedure written for a portfolio project. It does not describe any real firm.

Owner: Senior Bookkeeper. Every new client goes through these steps before any work starts.

## Identity verification { #identity-verification }

Before the engagement letter is signed, collect a copy of a government-issued photo ID for every owner who holds 25% or more of the client's business, and the company registration certificate. Compare the name on the ID with the name on the registration. Store the copies only in the client's restricted folder, never in email.

## Engagement letter { #engagement-letter }

Use the engagement letter template from the shared drive, `Templates/Engagement-Letter-v4.docx`. A partner must sign it. Work may not start until the client has returned a signed copy, and the signed copy is saved in the client's folder.

## Setting up the client in the system { #system-setup }

Create the client in the accounting system with the client code format `CL-` followed by four digits (for example `CL-0142`). Assign one bookkeeper as the owner and one reviewer. The reviewer must be a different person from the owner.

## Onboarding checklist deadline { #onboarding-deadline }

The whole checklist must be completed within 10 business days of the first meeting. If it is not, the Senior Bookkeeper tells the responsible partner.
